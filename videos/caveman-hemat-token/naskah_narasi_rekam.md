# Naskah rekam suara: "Caveman hemat token? Iya, tapi…"

Baca santai, sekitar 2,5 kata per detik. Total sekitar 175 kata, target sekitar 72 detik.
`/` = jeda pendek. `//` = jeda panjang (ganti visual). **Tebal** = tekan.

---

**[0:00]** Ada plugin viral / yang bikin AI ngomong kayak **manusia gua**. / Klaimnya: / hemat **65 persen** token. //

**[0:05]** Dan itu **bener**. / Tapi cuma **separuh cerita**. //

**[0:08]** Angka 65 persen itu dihitung dari **jawaban yang kamu baca**. / Contoh dari pembuatnya: / jawaban biasa 69 token, / versi caveman **19**. //

**[0:14]** Masalahnya, / banyak AI sekarang **mikir dulu** sebelum jawab. / Mirip kamu nyoret-nyoret di **kertas buram** / sebelum nulis di lembar ujian. / *(biarkan visual coretan "gaji 2 juta… salmon? mimpi" jalan sebentar)* / Coretan ini namanya **reasoning**. //

**[0:29]** Bedanya, / kertas buram AI bisa **ribuan** token, / dan sering nggak ditampilkan. / Tapi tetap **dihitung**. / Tetap **dibayar**. //

**[0:34]** Caveman cuma motong **lembar jawabannya**. / Kertas buramnya utuh. / Contoh: / mikir tiga ribu, / jawab seribu dua ratus. / Pakai caveman: / mikir tetap tiga ribu, / jawab tiga ratus. / Hematnya bukan 65 persen, / cuma sekitar **21 persen**. //

**[0:43]** **Plus**, / instruksi caveman-nya sendiri / nambah sekitar **seribu token input** / tiap giliran. //

**[0:49]** Pembuatnya sendiri **jujur**: / yang dipotong cuma output. / Reasoning dan input / nggak kesentuh. / Di jawaban yang udah pendek, / bisa malah **rugi**. //

**[0:56]** **Tipsnya**: / buat tugas gampang, / turunkan **level mikirnya**. / Pakai mode mikir rendah, / atau model tanpa reasoning. / Itu yang motong kertas buramnya. //

**[1:04]** Caveman bikin jawaban **enak dibaca**. / Tapi soal hemat, / yang mahal sering bukan jawabannya. / Tapi **mikirnya**.
